# Trabajo del equipo

La rama estable es `master`. Cada tarea usa una rama corta y PR con un revisor distinto al autor. El Project y los issues conservan los números de las guías enviadas al equipo.

- [Flujo y tablero](equipo/00-REVISION-Y-FLUJO.md)
- [Mauro: progreso, issue #2](equipo/01-MAURO.md)
- [Sergio: navegación, issue #3](equipo/02-SERGIO.md)
- [Christian: arte y audio, issue #4](equipo/03-CHRISTIAN.md)
- [Albert: importación inicial, issue #1](equipo/04-ALBERT-INTEGRACION.md)

Los comandos `git add`, `git commit`, push y apertura del PR están en cada guía. El primer PR incorpora el estado fuente existente bajo la identidad del integrador. Las contribuciones posteriores se registran bajo la identidad de quien las realiza.
